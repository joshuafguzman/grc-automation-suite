### 🚀 Featured Repositories

#### 📂 [grc-automation-suite](https://github.com/your-username/grc-automation-suite)
> *An enterprise-ready Python automation toolkit designed to streamline compliance auditing, continuous monitoring, and Plan of Action & Milestones (POA&M) generation.*
- **`cloud_grc_auditor.py`:** Multi-region AWS scanner auditing IAM console MFA, S3 default encryption, and unrestricted `0.0.0.0/0` ingress on management ports (SSH/RDP).
- **`nessus_to_poam.py`:** Transforms raw Tenable/Nessus vulnerability exports into standardized DoD / CMMC POA&M registers with automated SLA scheduling.
- **`evidence_integrity_verifier.py`:** Cryptographic SHA-256 evidence integrity and tamper-detection utility (*NIST AU-9 / CMMC 3.3.1*).
- **`ir_notification_timeline.py`:** Calculates statutory incident response notification clocks (*DoD DFARS 72h, MD MPIPA 45d, SEC 4-day Form 8-K*).
- **`vendor_risk_scorer.py`:** Automated third-party risk management scoring engine (*NIST SP 800-161*).
